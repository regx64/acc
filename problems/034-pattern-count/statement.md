# 문제
연구실에서 긴 유전자 서열 $T$ 안에 짧은 서열 $P$가 몇 번 나타나는지 세려고 합니다. 나타나는 위치는 서로 겹쳐도 됩니다. 예를 들어 `AAAA`에는 `AA`가 $3$번 나타납니다. 나타나는 횟수와, 처음 나타나는 위치를 구하세요. 위치는 $T$의 몇 번째 글자에서 시작하는지로 나타내며 1부터 셉니다.

# 입력
첫째 줄에 $T$, 둘째 줄에 $P$가 주어집니다. 두 서열은 `A`, `C`, `G`, `T`로만 이루어지며 길이는 $1$ 이상 $10^6$ 이하입니다.

# 출력
나타나는 횟수와 처음 나타나는 위치를 공백으로 구분해 출력합니다. 한 번도 나타나지 않으면 `0 -1`을 출력합니다.
