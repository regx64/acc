# 문제
물류 센터 $1$번에서 거점 $N$번으로 택배 상자를 최대한 많이 보내려고 합니다. 거점 $N$개 사이에 한 방향 운송로 $M$개가 있고, 운송로마다 하루에 실을 수 있는 상자 수(용량)와 상자 하나당 운송비가 있습니다. 중간 거점에서는 들어온 상자를 모두 그대로 내보냅니다.

보낼 수 있는 상자 수의 최댓값과, 그만큼 보낼 때 드는 운송비 합의 최솟값을 구하세요.

# 입력
첫째 줄에 $N$과 $M$이 주어집니다. ($2 \le N \le 100$, $0 \le M \le 1\,000$)

다음 $M$줄에 운송로의 시작 $u$, 끝 $v$, 용량 $c$, 상자당 운송비 $w$가 주어집니다. ($1 \le u, v \le N$, $u \ne v$, $1 \le c \le 100$, $0 \le w \le 1\,000$)

# 출력
상자 수의 최댓값과 운송비 합의 최솟값을 공백으로 구분해 출력합니다.
