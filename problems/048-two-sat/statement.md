# 문제
축제에 동아리 $N$개가 부스를 엽니다. 동아리마다 오전 또는 오후 중 한 때에만 부스를 엽니다. 동아리들의 요청 $M$개가 있는데, 요청마다 "동아리 $a$가 (오전/오후)이거나, 동아리 $b$가 (오전/오후)이어야 한다"는 형태입니다. 모든 요청을 들어줄 수 있는지 판단하세요.

요청은 두 정수 $a$, $b$로 주어집니다. 양수 $k$는 "$k$번 동아리가 오전", 음수 $-k$는 "$k$번 동아리가 오후"를 뜻합니다. 요청 $(a, b)$는 $a$가 뜻하는 조건과 $b$가 뜻하는 조건 중 적어도 하나가 참이어야 한다는 뜻입니다.

# 입력
첫째 줄에 $N$과 $M$이 주어집니다. ($1 \le N \le 100\,000$, $1 \le M \le 200\,000$)

다음 $M$줄에 $a$와 $b$가 주어집니다. ($1 \le |a|, |b| \le N$)

# 출력
모든 요청을 들어줄 수 있으면 `1`, 없으면 `0`을 출력합니다.
