# 문제
고속도로 위에 공사 지점 $N$곳이 출발점에서 가까운 순서로 있고, $i$번째 지점의 위치는 $x_i$입니다. 첫 번째 지점부터 차례로 나아가며 모든 지점을 공사하는데, 연속한 지점들을 묶어 한 구간씩 공사합니다. $j$번째부터 $i$번째 지점까지를 한 구간으로 공사하는 비용은 $(x_i - x_j)^2 + C$입니다.

모든 지점을 빠짐없이 한 번씩 공사하는 비용 합의 최솟값을 구하세요.

# 입력
첫째 줄에 $N$과 $C$가 주어집니다. ($1 \le N \le 300\,000$, $0 \le C \le 10^{12}$)

둘째 줄에 $x_1, \ldots, x_N$이 주어집니다. ($0 \le x_1 < x_2 < \cdots < x_N \le 10^6$)

# 출력
비용 합의 최솟값을 출력합니다.

# 힌트
구간 하나에 지점 하나만 있으면 그 구간의 비용은 $C$입니다.
