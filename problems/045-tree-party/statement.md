# 문제
회사 조직도는 $1$번 사장을 뿌리로 하는 트리입니다. 파티에 직원들을 초대하려는데, 어떤 직원과 그의 바로 위 상사를 함께 초대하면 분위기가 어색해지므로 그렇게 하지 않습니다. 직원 $i$를 초대하면 즐거움 $w_i$가 생깁니다. 초대한 직원들의 즐거움 합의 최댓값을 구하세요.

# 입력
첫째 줄에 $N$이 주어집니다. ($1 \le N \le 200\,000$)

둘째 줄에 $w_1, \ldots, w_N$이 주어집니다. ($0 \le w_i \le 10^9$)

셋째 줄에 $2$번부터 $N$번 직원의 바로 위 상사 번호 $N-1$개가 주어집니다. 조직도에 순환은 없습니다. ($N = 1$이면 셋째 줄은 비어 있습니다.)

# 출력
즐거움 합의 최댓값을 출력합니다.
