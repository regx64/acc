# 문제
시험 점수가 한 명씩 차례로 발표됩니다. 점수가 하나 발표될 때마다 지금까지 발표된 점수의 중간값을 구하세요. 발표된 점수가 $k$개일 때 작은 것부터 정렬해 $\lceil k/2 \rceil$번째 점수를 중간값으로 합니다.

# 입력
첫째 줄에 $N$이 주어집니다. ($1 \le N \le 300\,000$)

둘째 줄에 발표 순서대로 점수 $s_1, \ldots, s_N$이 주어집니다. ($-10^9 \le s_i \le 10^9$)

# 출력
점수가 발표될 때마다의 중간값 $N$개를 공백으로 구분해 한 줄에 출력합니다.
