# 문제
물류 센터는 $1$번 도시에 있습니다. 도시 $N$개가 일방통행 도로 $M$개로 이어져 있고, 도로마다 지나는 데 걸리는 시간이 정해져 있습니다. $1$번 도시에서 각 도시까지 가는 가장 짧은 시간을 구하세요.

# 입력
첫째 줄에 $N$과 $M$이 주어집니다. ($1 \le N \le 100\,000$, $0 \le M \le 300\,000$)

다음 $M$줄에 도로의 출발 도시 $u$, 도착 도시 $v$, 걸리는 시간 $t$가 주어집니다. ($1 \le u, v \le N$, $0 \le t \le 10^9$) 같은 두 도시 사이에 도로가 여러 개 있을 수 있습니다.

# 출력
$N$줄에 걸쳐 $1$번부터 $N$번 도시까지의 가장 짧은 시간을 출력합니다. 갈 수 없는 도시는 `-1`을 출력합니다.
