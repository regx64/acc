# 문제
어느 집안의 가계도에는 $N$명이 있고 $1$번이 가장 윗대 조상입니다. $1$번을 뺀 모든 사람에게는 부모가 한 명씩 있습니다. 두 사람 사이의 촌수는 가계도에서 한 사람에서 다른 사람까지 부모-자식 관계를 몇 번 거쳐야 하는지로 셉니다. 질문 $Q$개에 대해 두 사람의 촌수와 가장 가까운 공통 조상을 구하세요. 자기 자신도 자신의 조상으로 봅니다.

# 입력
첫째 줄에 $N$이 주어집니다. ($1 \le N \le 100\,000$)

둘째 줄에 $2$번부터 $N$번 사람의 부모 번호 $N-1$개가 주어집니다. 부모 번호는 자신의 번호보다 작지 않을 수도 있지만, 가계도에 순환은 없고 모두 $1$번의 자손입니다. ($N = 1$이면 둘째 줄은 비어 있습니다.)

셋째 줄에 $Q$가 주어집니다. ($1 \le Q \le 100\,000$)

다음 $Q$줄에 두 사람의 번호 $a$와 $b$가 주어집니다.

# 출력
질문마다 촌수와 가장 가까운 공통 조상의 번호를 공백으로 구분해 출력합니다.
