# 문제
놀이공원에 줄을 선 $N$명의 키를 모두 알고 있습니다. 놀이기구마다 키 제한 $x$가 있어서 키가 $x$ **이하**인 사람만 탈 수 있습니다. 놀이기구 $Q$개 각각에 대해 탈 수 있는 사람이 몇 명인지 구하세요.

# 입력
첫째 줄에 $N$과 $Q$가 주어집니다. ($1 \le N, Q \le 200\,000$)

둘째 줄에 키 $h_1, \ldots, h_N$이 주어집니다. ($1 \le h_i \le 10^9$)

셋째 줄에 키 제한 $x_1, \ldots, x_Q$가 주어집니다. ($1 \le x_j \le 10^9$)

# 출력
놀이기구마다 탈 수 있는 사람 수를 한 줄에 하나씩 출력합니다.
