# 문제
배달 로봇이 $0$번 창고에서 출발해 배달지 $1, 2, \ldots, N-1$을 한 번씩 모두 들른 뒤 창고로 돌아옵니다. $i$번 장소에서 $j$번 장소로 가는 비용 $c_{ij}$가 주어집니다. 비용은 방향에 따라 다를 수 있으며 $c_{ij} = -1$이면 그 방향으로 바로 갈 수 없습니다. 가능한 가장 적은 총비용을 구하세요.

# 입력
첫째 줄에 $N$이 주어집니다. ($2 \le N \le 16$)

다음 $N$줄에 $N$개씩 $c_{ij}$가 주어집니다. ($c_{ii} = 0$, $i \ne j$이면 $c_{ij} = -1$ 또는 $1 \le c_{ij} \le 10^6$)

# 출력
가장 적은 총비용을 출력합니다. 모두 들르고 돌아올 수 없으면 `-1`을 출력합니다.
