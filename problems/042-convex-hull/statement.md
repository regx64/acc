# 문제
목장에 말뚝 $N$개가 박혀 있습니다. 모든 말뚝을 안쪽 또는 경계에 두는 가장 작은 볼록 다각형 모양으로 울타리를 두르려고 합니다. 울타리의 꼭짓점 수와 울타리가 둘러싼 넓이를 구하세요. 한 직선 위에 있는 경계 위의 말뚝은 꼭짓점으로 세지 않습니다.

넓이는 정수가 아닐 수 있으므로 넓이의 $2$배를 출력합니다.

# 입력
첫째 줄에 $N$이 주어집니다. ($3 \le N \le 200\,000$)

다음 $N$줄에 말뚝의 좌표 $x$, $y$가 주어집니다. ($-10^9 \le x, y \le 10^9$) 같은 위치에 말뚝이 여러 개 있을 수 있으며, 모든 말뚝이 한 직선 위에 있지는 않습니다.

# 출력
꼭짓점 수와 넓이의 $2$배를 공백으로 구분해 출력합니다.
