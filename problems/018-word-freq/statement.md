# 문제
글에 쓰인 단어가 몇 번씩 나왔는지 표로 정리하려고 합니다. 많이 나온 단어부터, 나온 횟수가 같으면 사전순으로 앞서는 단어부터 적습니다. 표에는 위에서부터 $K$개만 적습니다. 서로 다른 단어가 $K$개보다 적으면 모두 적습니다.

# 입력
첫째 줄에 단어의 수 $N$과 $K$가 주어집니다. ($1 \le N \le 200\,000$, $1 \le K \le 1\,000$)

둘째 줄부터 영어 소문자로 된 단어 $N$개가 공백이나 줄바꿈으로 구분되어 주어집니다. 단어의 길이는 $1$ 이상 $20$ 이하입니다.

# 출력
표의 각 줄에 단어와 나온 횟수를 공백으로 구분해 출력합니다.
