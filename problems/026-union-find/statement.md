# 문제
학생 $N$명은 처음에 각자 혼자인 동아리에 속해 있습니다. 다음 두 가지 명령이 $Q$개 주어집니다.

- `U a b`: $a$가 속한 동아리와 $b$가 속한 동아리를 하나로 합칩니다. 이미 같은 동아리라면 아무 일도 없습니다.
- `Q a b`: $a$와 $b$가 같은 동아리인지 묻습니다.

`Q` 명령마다 답을 출력하고, 모든 명령이 끝난 뒤 가장 큰 동아리의 인원을 출력하세요.

# 입력
첫째 줄에 $N$과 $Q$가 주어집니다. ($1 \le N \le 200\,000$, $1 \le Q \le 200\,000$)

다음 $Q$줄에 명령이 하나씩 주어집니다. ($1 \le a, b \le N$)

# 출력
`Q` 명령마다 같으면 `YES`, 다르면 `NO`를 한 줄에 출력합니다. 마지막 줄에 가장 큰 동아리의 인원을 출력합니다.
