# 문제
섬마을 $N$곳을 전선으로 이어 모든 마을이 전기를 나눠 쓰게 하려고 합니다. 두 마을을 잇는 후보 전선 $M$개와 각각의 설치 비용이 주어집니다. 모든 마을이 전선을 따라 서로 이어지도록 전선을 골라 설치할 때 드는 최소 비용을 구하세요.

# 입력
첫째 줄에 $N$과 $M$이 주어집니다. ($1 \le N \le 100\,000$, $0 \le M \le 200\,000$)

다음 $M$줄에 전선이 잇는 두 마을 $u$, $v$와 비용 $c$가 주어집니다. ($1 \le u, v \le N$, $1 \le c \le 10^9$)

# 출력
최소 비용을 출력합니다. 모든 마을을 이을 수 없으면 `-1`을 출력합니다.
