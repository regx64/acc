# 문제
거꾸로 말하기 놀이에서는 문장의 단어 순서만 거꾸로 바꿉니다. 단어 안의 글자 순서는 그대로 둡니다.

영어 소문자로 된 단어들이 공백으로 구분된 문장이 여러 개 주어질 때, 각 문장의 단어 순서를 뒤집어 출력하세요.

# 입력
첫째 줄에 문장의 수 $T$가 주어집니다. ($1 \le T \le 100$)

다음 $T$줄에 문장이 하나씩 주어집니다. 문장은 단어 $1$개 이상으로 이루어지고, 단어 사이에는 공백이 정확히 하나 있으며, 줄 앞뒤에는 공백이 없습니다. 한 줄의 길이는 $1\,000$ 이하입니다.

# 출력
각 문장에 대해 `Case #i: ` 다음에 뒤집은 문장을 출력합니다. $i$는 1부터 셉니다.
