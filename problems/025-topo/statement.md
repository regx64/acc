# 문제
과목 $N$개에 $1$부터 $N$까지 번호가 붙어 있습니다. "$a$를 들은 뒤에 $b$를 들을 수 있다"는 선수 조건이 $M$개 있습니다. 한 학기에 한 과목씩 들을 때 모든 조건을 지키는 수강 순서를 정하려고 합니다. 가능한 순서가 여럿이면, 과목 번호를 차례로 나열한 수열이 사전순으로 가장 앞서는 순서를 고릅니다.

# 입력
첫째 줄에 $N$과 $M$이 주어집니다. ($1 \le N \le 100\,000$, $0 \le M \le 200\,000$)

다음 $M$줄에 $a$와 $b$가 주어집니다. ($1 \le a, b \le N$, $a \ne b$)

# 출력
수강 순서를 공백으로 구분해 한 줄에 출력합니다. 조건을 모두 지킬 수 없으면 `-1`을 출력합니다.
