# 문제
도시 $N$개가 일방통행 도로 $M$개로 이어져 있습니다. 두 도시 $a$, $b$에 대해 $a$에서 $b$로도, $b$에서 $a$로도 갈 수 있으면 두 도시가 같은 권역에 속한다고 합니다. 모든 도시는 자기 자신과 같은 권역입니다. 권역이 모두 몇 개인지와 가장 큰 권역에 속한 도시 수를 구하세요.

# 입력
첫째 줄에 $N$과 $M$이 주어집니다. ($1 \le N \le 100\,000$, $0 \le M \le 300\,000$)

다음 $M$줄에 도로의 출발 도시 $u$와 도착 도시 $v$가 주어집니다. ($1 \le u, v \le N$)

# 출력
권역의 수와 가장 큰 권역의 도시 수를 공백으로 구분해 출력합니다.
