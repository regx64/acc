# 문제
멘토 $N$명과 신입생 $M$명이 있습니다. 멘토마다 맡을 수 있는 신입생 목록이 주어집니다. 멘토 한 명은 신입생을 한 명까지만 맡고, 신입생 한 명에게는 멘토가 한 명까지만 붙습니다. 멘토와 신입생의 짝을 최대 몇 쌍 만들 수 있는지 구하세요.

# 입력
첫째 줄에 $N$, $M$, 그리고 맡을 수 있는 관계의 수 $E$가 주어집니다. ($1 \le N, M \le 2\,000$, $0 \le E \le 200\,000$)

다음 $E$줄에 멘토 번호 $a$와 신입생 번호 $b$가 주어집니다. ($1 \le a \le N$, $1 \le b \le M$)

# 출력
만들 수 있는 짝의 최대 수를 출력합니다.
