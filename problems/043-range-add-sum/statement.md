# 문제
회사에 직원 $N$명이 번호순으로 앉아 있고 각자 적립금이 있습니다. 다음 두 명령 $Q$개를 처리하세요.

- `1 l r x`: $l$번부터 $r$번까지 모든 직원의 적립금에 $x$를 더합니다. $x$는 음수일 수도 있습니다.
- `2 l r`: $l$번부터 $r$번까지 직원의 적립금 합을 출력합니다.

# 입력
첫째 줄에 $N$과 $Q$가 주어집니다. ($1 \le N, Q \le 200\,000$)

둘째 줄에 처음 적립금 $a_1, \ldots, a_N$이 주어집니다. ($|a_i| \le 10^9$)

다음 $Q$줄에 명령이 주어집니다. ($1 \le l \le r \le N$, $|x| \le 10^6$)

# 출력
`2` 명령마다 한 줄에 답을 출력합니다. 답은 항상 64비트 정수 범위 안에 있습니다.
