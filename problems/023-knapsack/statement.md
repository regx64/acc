# 문제
캠핑을 떠나는 하린이는 물건 $N$개 중 몇 개를 골라 배낭에 넣으려고 합니다. $i$번째 물건은 무게가 $w_i$, 쓸모가 $v_i$입니다. 넣은 물건의 무게 합은 $W$를 넘을 수 없고, 같은 물건을 두 번 넣을 수는 없습니다. 넣은 물건의 쓸모 합의 최댓값을 구하세요.

# 입력
첫째 줄에 $N$과 $W$가 주어집니다. ($1 \le N \le 100$, $1 \le W \le 100\,000$)

다음 $N$줄에 $w_i$와 $v_i$가 주어집니다. ($1 \le w_i \le 100\,000$, $0 \le v_i \le 10^9$)

# 출력
쓸모 합의 최댓값을 출력합니다.
