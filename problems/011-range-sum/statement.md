# 문제
하루도 빠짐없이 적금을 붓던 서준이는 날마다 넣은 금액을 기록해 두었습니다. $l$일부터 $r$일까지 넣은 금액의 합을 묻는 질문 $Q$개에 답하세요.

# 입력
첫째 줄에 날의 수 $N$과 질문의 수 $Q$가 주어집니다. ($1 \le N, Q \le 200\,000$)

둘째 줄에 날마다 넣은 금액 $a_1, \ldots, a_N$이 주어집니다. ($0 \le a_i \le 10^9$)

다음 $Q$줄에 $l$과 $r$이 주어집니다. ($1 \le l \le r \le N$)

# 출력
질문마다 한 줄에 합을 출력합니다.

# 힌트
질문마다 하나씩 더하면 최악의 경우 $4 \times 10^{10}$번 더해야 합니다. 앞에서부터의 누적 합을 미리 구해 두세요.
