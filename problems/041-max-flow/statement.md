# 문제
정수장 $1$번에서 물을 보내 배수지 $N$번에 모으려고 합니다. 교차점 $N$개 사이에 한 방향으로만 물이 흐르는 송수관 $M$개가 있고, 송수관마다 1초에 보낼 수 있는 최대량(용량)이 있습니다. 교차점에서는 들어온 물과 나가는 물의 양이 같아야 합니다. 1초에 $1$번에서 $N$번으로 보낼 수 있는 물의 최대량을 구하세요.

# 입력
첫째 줄에 $N$과 $M$이 주어집니다. ($2 \le N \le 500$, $0 \le M \le 5\,000$)

다음 $M$줄에 송수관의 시작 $u$, 끝 $v$, 용량 $c$가 주어집니다. ($1 \le u, v \le N$, $u \ne v$, $1 \le c \le 10^9$)

# 출력
최대량을 출력합니다.
