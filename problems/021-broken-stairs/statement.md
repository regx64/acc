# 문제
$0$번 칸에서 출발해 $N$번 칸까지 계단을 오릅니다. 한 번에 $1$칸, $2$칸 또는 $3$칸을 오를 수 있습니다. 그런데 몇몇 칸은 부서져 있어 밟을 수 없습니다. $N$번 칸에 도착하는 방법의 수를 $1\,000\,000\,007$로 나눈 나머지를 구하세요.

# 입력
첫째 줄에 $N$과 부서진 칸의 수 $B$가 주어집니다. ($1 \le N \le 10^6$, $0 \le B < N$)

$B > 0$이면 둘째 줄에 부서진 칸의 번호 $B$개가 주어집니다. 번호는 서로 다르며 $1$ 이상 $N-1$ 이하입니다.

# 출력
방법의 수를 $1\,000\,000\,007$로 나눈 나머지를 출력합니다.
