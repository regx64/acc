# 문제
코드 편집기의 괄호 검사 기능을 만듭니다. 문자열이 `(`, `)`, `[`, `]`, `{`, `}`로만 이루어져 있을 때, 다음을 만족하면 올바른 괄호 문자열입니다.

- 빈 문자열은 올바릅니다.
- $S$가 올바르면 `(S)`, `[S]`, `{S}`도 올바릅니다.
- $S$와 $T$가 올바르면 $ST$도 올바릅니다.

# 입력
첫째 줄에 문자열의 수 $T$가 주어집니다. ($1 \le T \le 1\,000$)

다음 $T$줄에 괄호 문자열이 하나씩 주어집니다. 길이는 $1$ 이상 $10\,000$ 이하이고, 모든 문자열 길이의 합은 $10^6$ 이하입니다.

# 출력
문자열마다 올바르면 `YES`, 아니면 `NO`를 출력합니다.
