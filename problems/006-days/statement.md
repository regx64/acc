# 문제
달력 앱에 넣을 기능을 만들고 있습니다. 연도와 월이 주어지면 그 달이 며칠까지 있는지 출력하세요.

윤년은 다음과 같이 정합니다.

- 연도가 400의 배수이면 윤년입니다.
- 그렇지 않고 100의 배수이면 평년입니다.
- 그렇지 않고 4의 배수이면 윤년입니다.
- 나머지는 평년입니다.

윤년의 2월은 29일, 평년의 2월은 28일입니다. 4, 6, 9, 11월은 30일, 나머지 달은 31일입니다.

# 입력
첫째 줄에 질문의 수 $T$가 주어집니다. ($1 \le T \le 1\,000$)

다음 $T$줄에 연도 $Y$와 월 $M$이 주어집니다. ($1 \le Y \le 10\,000$, $1 \le M \le 12$)

# 출력
질문마다 한 줄에 날짜 수를 출력합니다.
