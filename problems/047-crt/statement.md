# 문제
톱니바퀴 $N$개가 한 축에 달려 있고, $i$번째 톱니바퀴는 톱니가 $m_i$개입니다. 모든 톱니바퀴를 같은 속도로 한 칸씩 돌리는데, $i$번째 톱니바퀴의 표시 톱니는 $a_i$칸 돌렸을 때, 그 뒤로는 $m_i$칸 돌릴 때마다 맨 위에 옵니다. 모든 표시 톱니가 동시에 맨 위에 오는 가장 적은 회전 수 $x \ge 0$을 구하세요. 즉 모든 $i$에 대해 $x \equiv a_i \pmod{m_i}$인 가장 작은 음이 아닌 정수 $x$를 구합니다.

# 입력
첫째 줄에 $N$이 주어집니다. ($1 \le N \le 1\,000$)

다음 $N$줄에 $a_i$와 $m_i$가 주어집니다. ($1 \le m_i \le 10^9$, $0 \le a_i < m_i$)

# 출력
$x$를 출력합니다. 그런 $x$가 없으면 `-1`을 출력합니다. $x$는 매우 클 수 있습니다.
