# 문제
행성 $N$개 사이에 일방통행 포털 $M$개가 있습니다. 포털을 지나면 시간이 $t$만큼 흐르는데, $t$가 음수인 포털은 과거로 돌아갑니다. $1$번 행성에서 출발해 각 행성에 도착할 때 흐른 시간의 최솟값을 구하세요.

단, $1$번 행성에서 출발해 들를 수 있는 곳에 시간을 끝없이 되돌릴 수 있는 순환이 있으면, 최솟값이 정해지지 않으므로 `-1`만 출력합니다.

# 입력
첫째 줄에 $N$과 $M$이 주어집니다. ($1 \le N \le 500$, $0 \le M \le 6\,000$)

다음 $M$줄에 포털의 출발 행성 $u$, 도착 행성 $v$, 흐르는 시간 $t$가 주어집니다. ($1 \le u, v \le N$, $-10\,000 \le t \le 10\,000$)

# 출력
끝없이 되돌릴 수 있으면 `-1` 하나만 출력합니다. 그렇지 않으면 $2$번부터 $N$번 행성까지 한 줄에 하나씩 최솟값을 출력하되, 갈 수 없는 행성은 `-`를 출력합니다.
