# 문제
어느 주식의 $N$일 동안의 가격이 기록되어 있습니다. 기록이 잘못된 것을 발견하면 고치기도 합니다. 다음 두 가지 명령 $Q$개를 처리하세요.

- `1 i x`: $i$번째 날의 가격을 $x$로 고칩니다.
- `2 l r`: $l$번째 날부터 $r$번째 날까지의 가격 중 가장 낮은 값을 출력합니다.

# 입력
첫째 줄에 $N$과 $Q$가 주어집니다. ($1 \le N, Q \le 200\,000$)

둘째 줄에 가격 $p_1, \ldots, p_N$이 주어집니다. ($1 \le p_i \le 10^9$)

다음 $Q$줄에 명령이 주어집니다. ($1 \le i \le N$, $1 \le x \le 10^9$, $1 \le l \le r \le N$)

# 출력
`2` 명령마다 한 줄에 답을 출력합니다.
