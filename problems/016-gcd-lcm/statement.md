# 문제
두 막대의 길이 $A$와 $B$가 주어집니다.

- 두 막대를 남김없이 똑같은 길이의 조각으로 자르려고 할 때 가장 긴 조각의 길이를 구하세요.
- 길이 $A$인 막대와 길이 $B$인 막대를 각각 여러 개 이어 붙여 같은 길이를 만들 때, 가능한 가장 짧은 길이를 구하세요.

# 입력
첫째 줄에 질문의 수 $T$가 주어집니다. ($1 \le T \le 100\,000$)

다음 $T$줄에 $A$와 $B$가 주어집니다. ($1 \le A, B \le 10^{12}$)

# 출력
질문마다 두 답을 공백으로 구분해 한 줄에 출력합니다.
