# 문제
어느 섬의 토끼 수를 $F_n$이라 할 때 $F_0 = 0$, $F_1 = 1$이고 $n \ge 2$이면 $F_n = F_{n-1} + F_{n-2}$입니다. 질문마다 $n$이 주어지면 $F_n$을 $1\,000\,000\,007$로 나눈 나머지를 구하세요.

# 입력
첫째 줄에 질문의 수 $T$가 주어집니다. ($1 \le T \le 10\,000$)

다음 $T$줄에 $n$이 하나씩 주어집니다. ($0 \le n \le 10^{18}$)

# 출력
질문마다 한 줄에 답을 출력합니다.

# 힌트
$\begin{pmatrix} 1 & 1 \\ 1 & 0 \end{pmatrix}^n = \begin{pmatrix} F_{n+1} & F_n \\ F_n & F_{n-1} \end{pmatrix}$
